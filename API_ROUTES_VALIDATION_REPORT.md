# Отчет о проверке API и роутов для отображения неправильных ответов

## Проверенные компоненты

### 1. API `/api/tests/[id]` - Получение теста с вопросами

**Файл**: `app/api/tests/[id]/route.ts`

**Текущая реализация**:
- ✅ Загружает тест из БД (строки 22-45)
- ✅ Загружает вопросы по `questionIds` (строки 122-142)
- ✅ Возвращает вопросы напрямую из БД: `questionsArray.push(questionResult[0])` (строка 138)

**Потенциальная проблема**:
- ⚠️ Вопросы возвращаются как есть из БД без явного маппинга полей
- Drizzle ORM автоматически маппит `snake_case` колонки БД в `camelCase` поля схемы
- Но в компоненте есть fallback: `q.correctAnswer || q.correct_answer` (строка 437)

**Рекомендация**: ✅ Текущая реализация корректна, fallback в компоненте обеспечивает совместимость

## Структура данных

### Вопрос из API `/api/tests/[id]`:
```typescript
{
  id: string
  title: string          // Текст вопроса
  content: string        // Текст вопроса (альтернатива)
  type: string          // 'multiple_choice', 'true_false', 'text'
  options: string[]      // Варианты ответов
  correctAnswer: string  // Правильный ответ (или correct_answer)
}
```

### Попытка из API `/api/test-attempts`:
```typescript
{
  id: string
  testId: string
  userId: string
  answers: Record<string, string | string[]>  // questionId -> answer
  score: number | null
  status: string
  completedAt: string | null
}
```

### Данные в компоненте:
```typescript
testQuestions: Record<string, Question[]>  // testId -> questions[]
testAnswers: Record<string, Record<string, TestAttempt[]>>  // assignmentId -> userId -> attempts[]
```
