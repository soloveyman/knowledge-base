## 📋 Текущая логика обработки изображений

### Приоритеты загрузки (lib/image-loader.ts):

1. **URL из Spaces** (приоритет 1) - прямой URL из DigitalOcean Spaces CDN (все изображения)
2. **API lookup по imageId** (приоритет 2) - должен вернуть URL из Spaces

**Важно:** Base64 storage полностью отключен. Все изображения должны иметь URL в Spaces. Если изображения нет в S3 → оно недоступно.

### Рендеринг изображений (document-renderer.tsx):

1. **Data URLs** (`data:image/...`) - используют обычный `<img>` тег
2. **Внешние URL** (`https://...`) - используют обычный `<img>` тег (можно переключить на Next.js Image при необходимости)
3. **Обработка ошибок** - изображения скрываются при ошибке загрузки

## 🚨 Известные ограничения

1. **Next.js Image компонент:** Сейчас используется обычный `<img>` тег для всех изображений. Для использования Next.js Image нужно:
   - Настроить `next.config.ts` с доменами DigitalOcean Spaces
   - Обновить логику в компоненте img

2. **CORS:** Убедитесь, что DigitalOcean Spaces настроен с правильными CORS заголовками для доступа из браузера.
