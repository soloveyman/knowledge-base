# Политика хранения изображений

## ✅ Текущая политика

### Все изображения хранятся в S3 (DigitalOcean Spaces)

- ✅ **Base64 storage полностью отключен** (включая старые изображения)
- ✅ Все изображения **обязательно** загружаются в DigitalOcean Spaces
- ✅ URL из Spaces сохраняются в БД в таблице `document_images`
- ❌ Base64 **не поддерживается** - если изображения нет в S3, оно недоступно

## 📋 Логика работы

### При загрузке документа:

1. Изображения извлекаются из DOCX/XLSX
2. Все изображения загружаются в DigitalOcean Spaces
3. URL из Spaces сохраняются в БД
4. Если загрузка в S3 не удалась → изображение **пропускается** (не сохраняется base64)

### При отображении документа:

1. **Приоритет 1:** URL из Spaces (для всех изображений)
2. **Приоритет 2:** API lookup по imageId (должен вернуть URL из Spaces)

**Важно:** Если изображения нет в S3 (нет URL) → оно недоступно. Base64 fallback отключен.

## 🚨 Обработка ошибок

### Если загрузка в S3 не удалась:

- ❌ Изображение **не сохраняется** в БД с base64
- ⚠️ Логируется предупреждение
- 📝 Изображение пропускается при отображении

### Если изображение не найдено:

- ❌ Выбрасывается ошибка (не показывается broken image)
- 📝 Изображение пропускается при отображении

## 🔄 Миграция старых изображений

**Важно:** Старые изображения с base64 в БД **не будут работать** без URL в Spaces.

Для миграции:

1. Найти все изображения с `data IS NOT NULL AND url IS NULL`
2. Загрузить их в Spaces
3. Обновить `url` в таблице `document_images`
4. Удалить `data` (base64) из БД

**Без миграции:** Старые изображения без URL в Spaces будут недоступны.

## 📝 Изменения в коде

### lib/image-loader.ts

- Только URL из Spaces поддерживается
- Если нет URL → выбрасывается ошибка

### app/api/documents/images/[id]/route.ts
- Убран fallback на возврат base64 из БД
- Только URL из Spaces возвращается
- Если нет URL → 404 ошибка

### app/api/documents/route.ts
- Убран fallback на сохранение base64 в БД
- Если загрузка в S3 не удалась → изображение пропускается

### app/read/[documentId]/page.tsx
- Улучшена обработка ошибок загрузки изображений
- Изображения, которые не удалось загрузить, пропускаются (не показываются broken images)
